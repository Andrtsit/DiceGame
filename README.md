# Dice-Game(PIG):  A project inspired by Jonas Schmedtmann's JS course .

## 🚀 Project Overview

A browser-based Dice-Game (PIG)  built with vanilla JavaScript, CSS and HTML.
Game's target is for a player to collect 100 points by rolling the dice . 

## 📌 Features

- **Roll Dice**: When a player rolls a dice , all dices besides 1 give him the corresponding points .When 1 is rolled the player loses his turn and the opposite player can start rolling . Every time a player collects his points the opposite player can start rolling till he collects his points or rolling 1 . 
- **Collect**: When a player collects his current points , they are added to his overall score and its the opposite player turn to start rolling dices .
- **Reset** : This button resets the game, both players start with 0 points and its players 1 turn 
- ** Wining conditions **: First to 100 points overall wins the game ,where an alert window is popped up

## 🛠 Tech Stack

- **Vanilla JS**
- **CSS + HTML**
